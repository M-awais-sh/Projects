Step by Step procedure to run this project :



1- clone project in your computer.

2- go to backend folder and run CMD(command prompt) inside backend   folder.

3- Run this command in CMD **"python -m uvicorn main:app --reload"** (without quotations).

4- Now go to frontend folder and run CMD inside frontend folder.

5- Run this command in CMD **"python -m http.server 5500" (without quotations).**

**6- open your browser and paste this URL "http://localhost:5500" (without quotations).**





**PERKS**

**--> No changes required in any part of code.**

**--> No need to train model (Don't run Model\_training file)**

**--> Model accuracy 98+**
